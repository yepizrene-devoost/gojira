# Integration guide for anyone who wants to use gojira

A bilingual (English and Spanish) guide, linked from the README, that takes a person from nothing to a working gojira: install, create an Atlassian API token, configure, verify, and connect a terminal, an AI agent or an MCP client.

## Specs

- S1: "redactala y dejala en español e ingles enlazada al README del repo, no solo para mi PM si no para que cualquier persona que quiera usar gojira sepa como integrarla". One guide per language, linked from the README and to each other; written for any reader, not for one person.
- S2: "no crearemos oauth ahora mismo me es mas facil pedirle al pm que cree un api y decirle como crearla que todo este proceso me parece mas tardado e innecesario para una app que es local" and "sigue estando diferida hasta nuevo aviso la integración de oauth". The guide is built on the Atlassian API token. OAuth is not documented as a feature or promised.
- S3: "porque el repo es publico". Public repository: no personal names, no company names, no internal URLs or site names, no credentials, in either language.
- S4: Every fact is verifiable. Token facts come from the official Atlassian page "Manage API tokens for your Atlassian account" (creation URL, expiry from 1 to 365 days with a one-year default since 2024-12-15, authentication with the account email and the token, the token is shown only once, tokens with scopes use a different base address). Behaviour facts come from the gojira code and from the real binary: `config init` prompts for domain, email and token, then tests the connection; `config test`; token in the OS keychain with a YAML fallback; environment variables win; a `.env` in the current directory is loaded; `mcp config`.
- S5: Language. The repository convention is English documentation; the user explicitly asked for Spanish as well, so this artifact is the documented exception. Spanish is neutral and professional.
- S6: The README is the entry point: one link near the top to both guides, and its "Getting your Jira API token" section gains the expiry and the same link, in this same unit (AGENTS.md: update the README in the unit that changes behaviour or onboarding).
- S7: Review before commit (AGENTS.md): the work stays uncommitted until the user has seen it and asks for the closing cycle.
