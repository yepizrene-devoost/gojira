# Multiplatform installer scripts

## Objective
Add release-asset installer scripts for GoJira on Linux, macOS, and Windows, following the local dflow pattern, without publishing a release. The broad README accuracy pass is a separate later work unit requested by the user.

## Scope and contract
- Publish standalone `scripts/install.sh` and `scripts/install.ps1` with the next explicitly authorized `make release`; keep current local-only publishing policy.
- Pin explicit archive names for Linux/macOS/Windows on amd64 and arm64. Resolve the latest GitHub release or an explicitly requested version. Download matching archive and `checksums.txt`, verify SHA-256 before extraction and install, reject missing/unexpected binaries, clean up on failure, and install into a user-writable directory without sudo.
- Default to `$HOME/.local/bin` on POSIX and `%LOCALAPPDATA%/Programs/gojira` on Windows; permit a version override and an installation directory override where the platform permits it. Explain PATH on POSIX and update user PATH on Windows without clobbering existing entries.
- Add automated fixture checks for both installer entrypoints and execute the platform checks in CI where feasible. Never contact real GitHub or install into a real user directory in fixture checks.
- Do not change README in this installer-first unit, introduce package managers/signing/self-update, publish a release, or mutate GitHub issues.
